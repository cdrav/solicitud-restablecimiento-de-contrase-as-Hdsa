Actualización de Procesos

Desde el área de Sistemas se están mejorando las políticas y procesos de seguridad. Por tal motivo, todas las solicitudes de gestión de contraseñas se deben realizar obligatoriamente por este medio.

¿Cómo diligenciar el formulario?
  1. Información del Funcionario
    Complete sus datos personales, número de documento y seleccione el servicio al que pertenece.
  2. Selección de Sistema
    Haga clic sobre las opciones para seleccionar los sistemas.
    Importante: Solo se gestionan cuentas institucionales (@hdsa.gov.co). No se restablecen contraseñas de correos personales.
  3. Caso Especial: Registro Biométrico
    Si es un funcionario nuevo o requiere su primer registro en el sistema de huella, seleccione el sistema Registro Biométrico y el motivo Registro de Biometría. El área de Sistemas se pondrá en contacto para coordinar la captura.
  4. Observaciones
    Utilice este campo para añadir detalles específicos que ayuden al área de Sistemas a gestionar su caso (ej: "Bloqueo por intentos fallidos", "Contraseña olvidada para el PC de consulta externa", etc.).
  5. Envío
    Indique el motivo, acepte los términos de seguridad y haga clic en "Radicar Solicitud".
